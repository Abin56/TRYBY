================================================================================
  PART 1 — CARD ANATOMY
================================================================================

  The card has three layers:
    Layer A — Image Zone        (top, portrait image + all overlays)
    Layer B — Content Zone      (bottom, product details)
    Layer C — Interaction Zone  (hover-revealed actions)

  Card shell:
    Background:    #0F0F0F (--color-surface)
    Border:        1px solid #1C1C1C (--color-border)
    Border-radius: 16px (--radius-xl)
    Width:         260px carousel | 100% grid
    Aspect-ratio of full card: natural height (image 4/5 + content auto)
    overflow: hidden
    position: relative
    transition: border-color 200ms ease,
                box-shadow 200ms ease,
                transform 200ms ease

  HOVER STATE (card-level):
    border-color:  rgba(255, 59, 48, 0.25)
    box-shadow:    0 0 0 1px rgba(255,59,48,0.20),
                   0 8px 32px rgba(0,0,0,0.70),
                   0 0 20px rgba(255,59,48,0.15)
    transform:     translateY(-3px)


================================================================================
  PART 2 — LAYER A: IMAGE ZONE
================================================================================

  Container:
    Aspect-ratio:  4/5 (portrait — optimized for jersey/apparel)
    Background:    #141414 (--color-surface-raised)
    border-radius: 16px 16px 0 0
    overflow:      hidden
    position:      relative

  ── 2.1 JERSEY IMAGE ─────────────────────────────────────────────────────────

    Display:    object-fit cover, full area
    Alignment:  object-position: center top (shows collar + chest number clearly)
    Alt text:   "[Team Name] [Season] Official Jersey — Front View"

    HOVER:
      transform: scale(1.05)
      transition: transform 500ms cubic-bezier(0.25, 0.46, 0.45, 0.94)

    VIEW TOGGLE (Front / Back):
      On hover or tap: subtle crossfade between front and back image
      Delay: 300ms after hover begins (prevents flash on quick pass-through)
      Crossfade duration: 400ms ease
      Both images stacked, back image opacity: 0 by default → 1 on trigger
      Note: only activate if back image is supplied; degrade gracefully

  ── 2.2 BADGES — Top Left Stack ─────────────────────────────────────────────

    Position:  absolute, top: 12px, left: 12px
    Layout:    flex column, gap: 4px
    z-index:   20

    Rules:
      Show maximum 2 badges at once (priority order below)
      Never stack more than 2 — it kills visual hierarchy

    PRIORITY ORDER (show highest priority first):
      1. SALE badge      — shown when discount ≥ 10%
      2. LIMITED badge   — shown when stock ≤ 8 units
      3. TRENDING badge  — shown when in trending list
      4. NEW badge       — shown within 14 days of creation
      5. OFFICIAL badge  — always shown on licensed jerseys (can pair with any above)

    SALE BADGE:
      Background: #FF3B30 (--color-red-500)
      Text:       "–30% OFF" · Barlow Condensed 700 · 11px · UPPERCASE · white
      Padding:    3px 8px
      Radius:     4px (--radius-sm)
      Min-width:  auto (text-fit)

    LIMITED BADGE:
      Background: rgba(255, 184, 0, 0.90) (gold tint)
      Text:       "LIMITED" · same font · color: #000
      Padding:    3px 8px
      Radius:     4px
      Pulse animation: opacity 1→0.7→1, 2s infinite ease-in-out

    TRENDING BADGE:
      Background: rgba(255, 59, 48, 0.90)
      Text:       "🔥 TRENDING" · same font · white

    NEW BADGE:
      Background: rgba(0, 230, 118, 0.90) (--color-success)
      Text:       "NEW" · same font · color: #000

    OFFICIAL BADGE (Licensed Jerseys):
      Background: rgba(255, 184, 0, 0.92) (--color-gold-500)
      Text:       "✓ OFFICIAL" · same font · color: #000
      Icon:       Shield-check 10px before text

    ACCESSIBILITY:
      Each badge: role="img" aria-label="[badge meaning]"
      e.g. aria-label="30% discount" / "Limited stock" / "New arrival"

  ── 2.3 TEAM BADGE — Top Right (Image Zone) ─────────────────────────────────

    Position:  absolute, top: 12px, right: 56px
               (leaves room for wishlist button at far right)
    z-index:   20

    Container:
      Size:          36px × 36px
      Background:    rgba(8, 8, 8, 0.75)
      backdrop-filter: blur(8px)
      border:        1px solid rgba(255, 255, 255, 0.10)
      border-radius: 50%
      padding:       4px
      overflow:      hidden

    Image inside:
      Width: 100%, height: 100%
      object-fit: contain
      (Team crest/logo — circular crop)

    Fallback (no crest image):
      Background:    sport color (e.g. cricket green #4CAF50)
      Text:          2-letter team abbrev · JetBrains Mono 700 · 12px · white · centered

    TOOLTIP on hover/focus:
      "[Team Name] · [League/Tournament]"
      Style: glass-floating, radius-md, padding 4px 10px, Inter 12px white
      Position: below badge, left-aligned

  ── 2.4 WISHLIST BUTTON — Top Right ─────────────────────────────────────────

    Position:  absolute, top: 12px, right: 12px
    z-index:   20

    Shape:     40px × 40px circle
    Background: rgba(8, 8, 8, 0.72) glass
               (backdrop-filter: blur(8px))
    Border:    1px solid rgba(255, 255, 255, 0.08)

    Icon:      Heart (Lucide), 18px
      INACTIVE: color #A0A0A0 (stroke, not fill)
      ACTIVE:   color #FF3B30 (fill + stroke match)

    HOVER (inactive):
      Background: rgba(255, 59, 48, 0.15)
      Border-color: rgba(255, 59, 48, 0.30)
      Icon stroke: #FF3B30

    HOVER (active):
      Background: rgba(255, 59, 48, 0.20)

    TOGGLE ANIMATION:
      On activate:   scale(1.0) → scale(1.35) → scale(1.0), 300ms spring
                     (stiffness: 400, damping: 15)
      Particle burst: 6 tiny red dots radiate outward, fade out 400ms
                      (CSS-only: pseudo-elements or clip-path)

    aria-label:  "Add [Product Name] to wishlist" (inactive)
                 "Remove [Product Name] from wishlist" (active)
    aria-pressed: true / false

  ── 2.5 DISCOUNT CALLOUT — On Image, Bottom Right ───────────────────────────

    Shown only when discount ≥ 15% (significant enough to show twice)

    Position:  absolute, bottom: 56px, right: 12px
               (sits just above the Quick Add bar)
    z-index:   15

    Shape:     Circle, 48px × 48px
    Background: linear-gradient(135deg, #FF3B30 0%, #CC2F26 100%)
    Box-shadow: 0 0 12px rgba(255, 59, 48, 0.45)

    Text (two lines, centered):
      Line 1: "–30%"  · JetBrains Mono 700 · 13px · white
      Line 2: "OFF"   · Barlow Condensed 600 · 10px · white · UPPERCASE

    Border:    2px solid rgba(255, 255, 255, 0.15)
    Border-radius: 50%

    HOVER: scale(1.08), 150ms ease

    NOTE: Do NOT show if SALE badge is already visible in top-left.
          Use one or the other, not both.

  ── 2.6 QUICK VIEW TRIGGER — Bottom Image ───────────────────────────────────

    Position:  absolute, bottom: 0, left: 0, right: 0
    z-index:   18

    DEFAULT STATE: opacity: 0, translateY(6px)
    HOVER STATE:   opacity: 1, translateY(0)
                   Transition: 200ms ease-out (delay 50ms after card hover)

    Container:
      Height:      38px
      Background:  rgba(14, 14, 14, 0.90)
                   backdrop-filter: blur(12px)
      Border-top:  1px solid rgba(255, 255, 255, 0.06)

    Layout:        flex row, center + space-between, padding: 0 14px
    Left:          Eye icon (Lucide, 15px, #A0A0A0) + "Quick View" (Inter 500 12px #A0A0A0)
    Right:         → chevron (12px, #606060)

    HOVER on bar itself:
      Background: rgba(20, 20, 20, 0.95)
      Left text + icon → white
      Right chevron → #A0A0A0
      Transition: 150ms ease

    ON CLICK: Opens Quick View drawer/modal (see Part 6)

    MOBILE: Quick View trigger replaced by a tap on the image itself.
            No hover state on mobile — tap image to open Quick View.

  PART 3 — LAYER B: CONTENT ZONE
================================================================================

  Container:

  ── 3.1 SPORT + LEAGUE EYEBROW ───────────────────────────────────────────────

    SEPARATOR DOT:

    LEAGUE TAG:
      Text:          e.g. "IPL 2026" · Inter 500 · 11px · #606060

    PERSONALIZATION CTA (optional — jerseys only):
      Far right of row (margin-left: auto)
      Text: "+ Add Name" · Inter 500 · 11px · #FF3B30
      Visible only if product supports name/number customization
      HOVER: underline

  ── 3.2 PRODUCT NAME ─────────────────────────────────────────────────────────

    Text:          Inter 500 · 14px · #FFFFFF · line-height: 1.4
    Display:       -webkit-box · -webkit-line-clamp: 2 · overflow: hidden
    Margin:        4px 0 8px 0

    Example: "Mumbai Indians Home Jersey 2026 — Official Edition"

    HOVER (card hover):  color: #FFFFFF (stays white, no change needed)

  ── 3.3 RATING ROW ───────────────────────────────────────────────────────────

    Layout:        flex row, gap: 6px, align-items: center
    Margin-bottom: 10px

    STARS:
      5 star icons (Lucide Star filled/half), 13px each
      FILLED: color #FFB800 (--color-gold-500)
      EMPTY:  color #2A2A2A
      HALF:   left-half filled (SVG clip-path on half star)
      Display to 1 decimal (e.g. 4.3 shows 4 filled + 1 half)

    RATING NUMBER:
      "4.8" · JetBrains Mono 500 · 12px · #FFFFFF

    REVIEW COUNT:
      "(2,341)" · Inter 400 · 11px · #606060

    VERIFIED DOT (if >100 reviews):
      Small green dot (6px, bg #00E676) + "Verified" · Inter 400 · 10px · #00E676
      Left-margin: 4px from count

    NO RATINGS STATE:
      Replace entire row with: "Be the first to review" · Inter 400 · 11px · #606060

  ── 3.4 SIZES AVAILABLE ROW ──────────────────────────────────────────────────

    Purpose:    Reduces PDP visits. Buyer sees fit instantly.
    Layout:     flex row, gap: 4px, flex-wrap: nowrap, overflow: hidden
    Margin-bottom: 10px

    LABEL (leading):
      "Sizes:" · Inter 400 · 11px · #606060

    SIZE CHIPS:
      Each chip:     min-width: 32px, height: 24px, padding: 0 6px
      Background:    transparent
      Border:        1px solid #282828
      Border-radius: 4px (--radius-sm)
      Text:          Inter 500 · 11px · #A0A0A0 · UPPERCASE
      Examples:      XS | S | M | L | XL | XXL

      IN STOCK chip:
        Border:  1px solid #282828
        Text:    #A0A0A0

      OUT OF STOCK chip:
        Border:  1px solid #1C1C1C
        Text:    #3A3A3A
        Diagonal strikethrough line (CSS: linear-gradient overlay)

      HOVER on IN STOCK chip:
        Border: 1px solid rgba(255,59,48,0.40)
        Text:   #FFFFFF
        Transition: 120ms ease

    OVERFLOW PILL:
      If > 5 sizes: show 4 chips + "+2 more" pill
      "+2 more" pill: bg #1A1A1A · border #282828 · text #606060 · 11px Inter 400

    ACCESSIBILITY:
      fieldset + legend "Available sizes for [product name]"
      Each chip: role="button" aria-label="Size [S] available" / "Size [XL] out of stock"

  ── 3.5 PRICE ROW ────────────────────────────────────────────────────────────

    Layout:     flex row, align-items: center, gap: 8px, flex-wrap: wrap
    Margin-bottom: 12px

    CURRENT PRICE:
      Text:      "₹1,299" · JetBrains Mono 700 · 20px · #FFFFFF
      (Mono font makes prices feel precise and trustworthy — from Kitbag/Nike)

    ORIGINAL PRICE (only when discounted):
      Text:      "₹1,999" · JetBrains Mono 400 · 14px · #606060 · text-decoration: line-through

    DISCOUNT PILL (only when discounted):
      Text:      "–35%" · Inter 600 · 11px · white
      Background: rgba(255, 59, 48, 0.18)
      Border:    1px solid rgba(255, 59, 48, 0.30)
      Padding:   2px 7px · radius-full

    SAVINGS LABEL (below price row, optional — shows for discounts ≥ 20%):
      "You save ₹700" · Inter 400 · 11px · #00E676 (green)
      Margin-top: 2px

    FREE DELIVERY INLINE TAG (optional — shows if product qualifies):
      Right side of price row, pushed by margin-left: auto
      "Free Delivery" · Inter 500 · 11px · #00E676
      Small truck icon 11px before text

  ── 3.6 SOCIAL PROOF TICKER ──────────────────────────────────────────────────

    Shown on: Trending + Best Seller cards (not all cards — only where earned)
    Layout:   flex row, gap: 6px, align-items: center
    Margin-bottom: 0 (last item before CTA row)

    SOLD TICKER:
      Icon:  Flame (Lucide 12px, #FF9800)
      Text:  "1,247 sold today" · Inter 500 · 11px · #FF9800

    LOW STOCK WARNING (shown when stock ≤ 5, overrides sold ticker):
      Icon:  AlertCircle (Lucide 12px, #FFB800)
      Text:  "Only 3 left" · Inter 600 · 11px · #FFB800
      Pulse: opacity 1→0.6→1, 1.5s infinite

    STOCK BAR (below the ticker text, only on Trending cards):
      Height:        3px
      Width:         100% of content zone
      Background:    #1C1C1C
      Fill:          linear-gradient(90deg, #FF3B30 0%, #FFB800 100%)
      Fill-width:    percentage of stock remaining (e.g. 30% = "3 of 10 left")
      Border-radius: 2px
      Margin-top:    4px

  ── 3.7 ADD TO CART BUTTON ───────────────────────────────────────────────────

    Position:   bottom of content zone, full-width
    Height:     44px
    Background: linear-gradient(135deg, #FF3B30 0%, #CC2F26 100%)
    Text:       "ADD TO CART" · Barlow Condensed 700 · 14px · white · UPPERCASE · tracking: 0.06em
    Border:     none
    Radius:     8px (--radius-md)
    Box-shadow: 0 2px 8px rgba(255, 59, 48, 0.40)

    ICON:
      ShoppingBag (Lucide) 16px · white · margin-right: 8px

    HOVER:
      Background: linear-gradient(135deg, #E5352B 0%, #B82822 100%)
      box-shadow: 0 4px 16px rgba(255, 59, 48, 0.55)
      transform:  translateY(-1px)
      transition: all 150ms ease

    PRESS / ACTIVE:
      transform: scale(0.98) translateY(0)
      box-shadow: none
      transition: all 80ms ease

    LOADING STATE (after click, while API call resolves):
      Text replaced with spinner (3 dots pulsing or ring spinner)
      opacity: 0.85
      cursor: not-allowed
      pointer-events: none

    SUCCESS STATE (cart add confirmed):
      Background: #00E676 (green)
      Text: "✓ ADDED!" · same font
      Duration: 1.8s then reverts to default
      Animation: scale 1→1.04→1, 200ms

    SIZE NOT SELECTED STATE (if product has sizes):
      Background: #282828 (dimmed)
      Text: "SELECT A SIZE" · same font style
      Cursor: pointer (still clickable → triggers size selector)
      Box-shadow: none

      ON CLICK (when no size selected):
        Size chips above pulse with ring highlight 2×, 400ms

    OUT OF STOCK STATE:
      Background: #1A1A1A
      Text: "OUT OF STOCK" · same font · #606060
      Cursor: not-allowed
      Box-shadow: none

      Below button: "Notify me when available →" link
        Inter 500 · 12px · #2563EB (blue) · underline on hover

    ACCESSIBILITY:
      aria-label: "Add [Product Name], size [S], to cart"
      aria-disabled: true when OOS
      aria-busy: true during loading

    TOUCH:
      min-touch-target: 44px (already satisfied by height)
      No double-tap requirement

  PART 4 — CARD VARIANTS

  ── 4.1 STANDARD CARD (Grid / Carousel) ──────────────────────────────────────

    Everything in Parts 2 & 3 as described above.
    This is the default. Used in: Trending, Best Sellers, Search Results.

  ── 4.2 FEATURED JERSEY CARD ─────────────────────────────────────────────────

    Used in: Featured Jerseys section (Section 4.4 in homepage spec)
    Width:   240px carousel | fixed width
    Aspect:  3/4 (taller — jersey-specific ratio from Fanatics/Kitbag)

    DIFFERENCES vs Standard Card:
      • Team badge size increased to 44px
      • Team name rendered in content zone as primary text (replaces product name)
        — Barlow Condensed 700 · 20px · UPPERCASE · white
      • League/Tournament below team name
        — Inter 400 · 12px · #A0A0A0
      • "OFFICIAL" gold badge always visible (top-left, first in stack)

      • Price row: smaller — JetBrains Mono 600 · 16px
      • CTA: "Shop Kit" instead of "Add to Cart" (goes to PDP)
      • Full-height image with gradient overlay bottom (transparent → #141414 80%)
        — Content zone sits ON image (no white/grey split)

  ── 4.3 BEST SELLER CARD ─────────────────────────────────────────────────────

    NOTE: Ribbon replaces the badge stack for best seller cards.
          If product also has a sale, show ribbon (best seller wins hierarchy).

  ── 4.4 COMPACT CARD (Mobile 2-col grid) ─────────────────────────────────────

    Width:   calc(50vw - 20px) on mobile (two per row with 16px gap + 12px edge)

    DIFFERENCES vs Standard Card:

      • Discount callout circle on image: hidden
      • Quick View bar: hidden (replaced by tap-to-view on image)
      • Personalization CTA: hidden
      • Sizes row: shows only 4 chips max, no "+N more" expansion
      • Price row: JetBrains Mono 700 · 16px (slightly smaller)
      • Add to Cart: height 40px, text "ADD" (shorter)
      • Margin-bottom on content zone: 12px
      • Rating row: 3 stars visible + number only (no review count on smallest)

  ── 4.5 SKELETON CARD (Loading State) ────────────────────────────────────────

    }

    BLOCKS:

      Price:         80px × 20px
      Button:        full-width × 44px, radius 8px, margin-top 12px

  ── 6.3 HOVER INTERACTION SEQUENCE ──────────────────────────────────────────

  t=0ms:    mouse enters card
  t=0ms:    card border-color transitions to red-tint
  t=0ms:    card lifts (translateY: -3px)
  t=0ms:    card box-shadow activates (glow-card-hover)
  t=100ms:  image scale begins (0ms delay if fast hover, 100ms debounce)
  t=200ms:  Quick View bar slides up (from image bottom)
  t=300ms:  image crossfades to back view (if back image exists)
  t=0ms:    wishlist button hover state applies

  On mouse leave (any point):
    All transitions reverse using the same duration
    Image scale reverses: 400ms ease
    Card lift reverses: 200ms ease
    Quick View bar: fade out 150ms

================================================================================
  PART 12 — DECISION LOG (WHY THESE CHOICES)
================================================================================

  1. 4/5 ASPECT RATIO (image zone)
     Nike, Adidas, Fanatics all use portrait ratios for apparel.
     4/5 shows collar, chest print, and hem — the 3 zones buyers evaluate.
     Wider (1/1) cuts off bottom; taller (2/3) wastes space. 4/5 is optimal.

  2. TEAM BADGE ON IMAGE (not content zone)
     Kitbag and Fanatics place crests on the product photo overlay.
     It mirrors how a physical jersey looks — crest on chest.
     Moves from generic card to jersey-specific identity immediately.

  3. QUICK VIEW ON HOVER (not click)
     Nike and Adidas use hover-reveal. Reduces PDP bounce rate.
     On mobile, tap-to-view replaces hover (no hover on touch devices).
     Fanatics uses a dedicated Quick View button — we use the full image
     area as target for better touchability.

  4. SIZE CHIPS IN CARD (not just PDP)
     Reduces the most common friction point: "does this come in my size?"
     Eliminates PDP visit just to discover OOS. Fanatics pioneered this.
     Out-of-stock chips with strikethrough borrowed from Adidas.

  5. MONOSPACE FONT FOR PRICE
     JetBrains Mono for prices gives a "precision" feel — like a sports
     scoreboard or a financial ticker. Differentiated from Inter body text.
     Creates visual hierarchy without needing bold alone.

  6. VIEW TOGGLE (Front/Back)
     Kitbag's signature feature. Jersey buyers want to see the back
     (number, player name area). Crossfade on hover is elegant — no
     button to click, just dwell.

  7. WISHLIST PARTICLE BURST
     High-delight micro-interaction. Borrowed from Twitter's like button.
     Reinforces save action. Skipped on reduced-motion preference.

  8. CARD LIFT ON HOVER (translateY -3px)
     3px chosen carefully — 2px feels imperceptible, 4px feels cheap.
     Combined with glow shadow creates a "premium lift" used by Linear,
     Stripe, and Raycast (brand references for this project).

  9. DISCOUNT CIRCLE ON IMAGE vs BADGE IN STACK
     Circle on image mimics a "price sticker" — tactile, physical.
     Only shown for ≥15% discount so it feels earned, not generic.
     Fanatics and Kitbag use this pattern on sale items.

  10. SOLD TICKER + STOCK BAR (Trending only)
      Not on every card — only where earned. Overuse of scarcity signals
      destroys trust. Applied only to cards in Trending/Best Seller context
      where the data is real. Stock bar gives visual percentage urgency.
