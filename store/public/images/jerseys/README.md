## Image requirements:
- Format: JPG or PNG
- Background: White or transparent
- Style: Clean catalogue / product photography
- Ratio: 1:1 square
- Resolution: Minimum 400×400px
- Subject: Jersey centred, no models, no lifestyle

## Fallback:
If an image file is missing, the app automatically shows a branded
SVG jersey silhouette using the correct team colours.
No broken images will be shown.
