## 8. Running the seed

```bash
# from store/
npx prisma generate        # ensure client matches schema (first time / after schema changes)
npx prisma db push         # ensure the staging DB has all tables (or: prisma migrate deploy)

npm run seed:test          # idempotent upsert — safe to re-run
npm run seed:test:reset    # wipe all tst_ rows, then re-seed fresh
```

**Safety:** the script refuses to run when `NODE_ENV=production` (override only on a
disposable staging DB with `ALLOW_TEST_SEED=1`). It prints the target DB host (credentials
masked) before writing. Reset deletes **only** `tst_`-prefixed rows.
