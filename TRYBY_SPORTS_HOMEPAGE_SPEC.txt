================================================================================
  SECTION 7 — ANIMATION STRATEGY
================================================================================

  PHILOSOPHY:
    "Performance-first, then delight."
    Animations must never block interactivity.
    Every animation has a purpose (guide attention, confirm action, reduce perceived wait).
    Duration budget: max 600ms for any entrance. Max 200ms for interactions.

  ANIMATION INVENTORY:

  1. PAGE LOAD SEQUENCE (cascading, total ~1s):
     t=0ms:   Navbar fades in (opacity 0→1, 200ms)
     t=100ms: Hero eyebrow slides up (y:12→0, 300ms)
     t=200ms: Hero headline words stagger in (0.08s each, spring)
     t=500ms: Hero body + CTA slides up
     t=700ms: Hero image slides in from right (x:40→0, 400ms)
     t=800ms: Floating stat cards pop in (scale 0.8→1, spring)
     t=900ms: Trust bar fades in

  2. SCROLL-TRIGGERED ENTRANCES:
     Trigger: element enters viewport (IntersectionObserver, threshold 0.15)
     Default: { opacity:0, y:24 } → { opacity:1, y:0 }, 400ms ease-out
     Stagger: 0.08s between siblings (product cards, stat cards)
     Run once: true (no re-animation on scroll-back)

  3. INTERACTION MICRO-ANIMATIONS:
     Button press:       scale(0.98), 100ms
     Button hover:       translateY(-1px) + shadow increase, 150ms
     Card hover:         translateY(-2px) + glow border, 200ms
     Wishlist toggle:    heart scale(1.4) then back, spring 300ms
     Cart badge count:   scale spring when count changes
     Tab switch:         layout animation + content fade, 200ms
     Accordion open:     height auto animation, 300ms ease-out
     Nav link hover:     color transition + underline slide, 150ms

  4. MARQUEE REVIEWS:
     CSS: animation: marqueeLeft 40s linear infinite
     @keyframes marqueeLeft: { from: translateX(0), to: translateX(-50%) }
     Second row: marqueeRight (reverse)
     Pause: animation-play-state: paused on hover
     Prefers-reduced-motion: animation-duration: 0.01ms

  5. COUNT-UP ANIMATION:
     Stats (50,000+, 4.8, etc.)
     Library: custom hook using requestAnimationFrame
     Duration: 1.5s ease-out
     Trigger: on scroll-enter
     Format: locale string (50,000 not 50000)

  6. JERSEY CARD HOVER:
     Image scale(1.05): 400ms ease
     Overlay darkens: opacity +0.15, 300ms
     "Explore →" CTA: translateY(4px)→(0), opacity 0→1, 200ms

  7. FLOATING STAT CARDS (hero):
     useAnimation loop: { y: [0, -8, 0] }
     Each card: different duration (3s, 3.4s, 3.8s) for natural feel
     ease: "easeInOut"

  8. PAGE TRANSITIONS (route changes):
     Exit: opacity 1→0, translateY 0→-8px, 200ms
     Enter: opacity 0→1, translateY 8px→0, 200ms
     Implemented via layout.tsx AnimatePresence wrapper
